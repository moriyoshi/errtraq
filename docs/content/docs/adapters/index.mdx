All packages are named `@moriyoshi/errtraq-<name>`. Selection helpers come from the `/stack` export of each package.

## Available now

| Port | Adapter | Package | Helper |
| --- | --- | --- | --- |
| Active store | SQLite | `store-sql` | `sqlite` |
| Active store | PostgreSQL (password secret or RDS IAM) | `store-sql` | `postgres` from `store-sql/postgres/stack` |
| Active store | DynamoDB | `store-dynamodb` | `dynamoStore` |
| Queue | In-memory | `queue-memory` | `memoryQueue` |
| Queue | Amazon SQS | `queue-sqs` | `sqsQueue` |
| Blob store | Filesystem | `blob-fs` | `fsBlob` |
| Blob store | Amazon S3 | `blob-s3` | `s3Blob` |
| KV | In-memory | `kv-memory` | `memoryKv` |
| KV | DynamoDB | `kv-dynamodb` | `dynamoKv` |
| Platform | Standalone Node.js | `platform-standalone` | `standalone` |
| Platform | AWS Lambda | `platform-aws-lambda` | `awsLambda` |

Supporting packages: `core` (ports, domain, stack validation), `http` (Hono apps), `cli` (the `errtraq` command),
`infra-gen` (Terraform generator) and `aws-signing`.
